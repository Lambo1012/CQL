Для сортировки записей используется конструкция ORDER BY 

Направление сортировки: 
- ASC - по возрастанию( по умолчанию ).
- DESC - по убыванию. 

Что сортирует: 
- Числовой тип. ASC - от меньшего к большему .  DESC - от большего к меньшему. 
- строковый тип. ASC -  от "A" до "Z" (или от "A" до "Я"). 
DESC - От "Z" до "A" (или от "Я" до "А").
- Дата и время. ASC - от более ранней даты к более поздней. 
DESC  - от более поздней даты к более ранней. 
- Булевый тип.  ASC - false идёт перед true. DESC - true идёт перед false.
- NULL значения.  ASC - NULL значения идет первыми. DESC -NULL значения идут последними. 

Оператор ORDER BY - не обязателен. 

Может сортировать по нескольким атрибутам. Приоритет слева на право которые вы укажите в ORDER BY. 

Пример: 
SELECT pay, name 
FROM Company
ORDER BY name DESC, pay
