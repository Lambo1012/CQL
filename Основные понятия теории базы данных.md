### Определение данные 

Информация представленная в определенном виде может быть хаотичным или упорядоченным в информации. 

### Базы данных (БД)

Совокупность данных организованных по определенным правилам Предусматривающая хранение описание, манипулирование и удаление данных. 

### Система управление базы данных (СУБД)

Это целый комплекс программ позволяющий создавать базу данных и манипулировать данные. 

### Популярные СУБД 
- Microsoft SQL Server (MS SQL Server)
- MySQL 
- Oracle 
- PostgreSQL
- MongoDB
 При использование базы данных используется SQL. 
 
### Язык запросов SQL 

Это специальный язык предназначенный для работы с БД. Не язык программирования. 

### Особенности SQL 

- Это не является самостоятельным языком программирования. 
- Оно используется для взаимодействия базы данных. 
- Имеет четкую структуру близок к естественному английскому языку. 
- Имеет декларативный характер. 
- При написание кода пользователь указывает что хочет получить а система сама определяет как выполнить задачу.
- В нем нет циклов ветвей и других привычных конструкции.
### Список диалектов языка SQL 

1. T-SQL (TransacrSQL) -  Используется в MS SQL Server 
2. PL/SQL (Procedural Language /SQL) Используется в Oracle 
3. SQL/PSM  - используется в MySQL  
4. PLpg/SQL - используется в PostgreSQL
5. Jet SQL - используется в Microsoft Access

### Архитектура файл сервер 

Участвует персональный компьютер и выделенный сервер на котором будет храниться файлы.  Сервер не участвует в обработке своих данных он только хранит. 

Пример: Все файлы  находящийся на сервере можно менять и удалять, но при этом  может произойти конфликт. 
### Преимущество 

1. Девшего и легко настроить и сделать общий доступ.
2. Каждый использует свою мощность ПК для вычислений 
### Недостатки 

1. Огромный трафик. 
2. Конфликт.

### Модели БД 

Это способ структурирования  данных и описание взаимосвязи между ними. 

1. Файловая модель - состоит из поля и файла записи, нет связи между файлами.
2. Иерархическая модель - появилась связь между данными, а именно родитель потомок. 
3. Сетевая модель - представляет собой развитие иерархической модели, модель позволяет описывать более сложные виды взаимосвязи между данными, появляется связь многое ко многому. 
![[Pasted image 20260908145649.png]]

4. Реляционная модель (самая популярная) -  данная представляется в виде таблиц, в этой модели присутствую связи 1к1, 1 к многому и много к многому. 
5. Гибридная . 
### Основные понятия реляционной модели 

1. Сущность (таблица) - представления набора реальных или абстрактных объектов(Люди, аудитории, событие, места и тд) которые имеют общие характеристики, 
2. Атрибут (подзаголовок столбца) - именование характеристик являются частью сущности. 
3. Картеж (одна строка) - это каждая строка сущности которые хранятся данные разных типов.
